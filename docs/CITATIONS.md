# Citations

## Apple frameworks

Billfold uses Apple frameworks only. No third-party libraries are included.

| Framework | Used for | Documentation |
|---|---|---|
| SwiftUI | All screens and components | https://developer.apple.com/documentation/swiftui |
| SwiftData | Saving expenses on the device | https://developer.apple.com/documentation/swiftdata |
| Vision | On-device text recognition (`VNRecognizeTextRequest`) | https://developer.apple.com/documentation/vision |
| PhotosUI | Picking a receipt photo (`PhotosPicker`) | https://developer.apple.com/documentation/photosui |
| Swift Charts | Donut and bar charts on the Insights screen | https://developer.apple.com/documentation/charts |
| Foundation | `NSRegularExpression`, `NSDataDetector`, formatting | https://developer.apple.com/documentation/foundation |
| UIKit | `UIImage` and `UIGraphicsImageRenderer` | https://developer.apple.com/documentation/uikit |

## Other resources
